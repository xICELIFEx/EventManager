Краткое описание проекта:
Данный проект это веб приложение для работы с событиями. На данный момент поддерживаются только CRUD операции над
событиями и простую модель события.

Инструкция по запуску:
Вариант 1:

1. В консоли перйти в папку с проектом EventManager
2. Выполнить команду: dotnet run
   Вариант 2:
1. Открыть решение в IDE
2. Найти в контекстном меню проекта EventManager команду Run и выполнить её
